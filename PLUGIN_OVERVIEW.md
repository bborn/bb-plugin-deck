One searchable list of every thread you have, and enough context beside it to
answer one and move on.

## What you get

- **Search that finds anything you remember**: a Linear ticket, a PR number, a
  branch, a project, a tag, roughly when it was, or a phrase the agent said.
  It reaches archived threads too, which is where most finished work lives.
- **States you never set.** An agent is working, an agent is waiting on you, or
  it is done. All three are read off the thread, so there is nothing to drag
  and nothing to keep tidy. What needs you sorts to the top, in red.
- **A context pane** with the agent's standing one-line summary, what it is
  blocked on, the branch and PR, and its last message, plus a box to reply
  without leaving the list.
- **Keyboard first.** Slash to search, j and k to move, Enter to open, r to
  reply, e to archive, and number keys for saved views.
- **Saved views**, so a filter you use every day is one keystroke.

## How it works

The list is bb's own live thread data, so it is never stale. The plugin adds
what bb does not keep: tags, the agent's standing note, saved views, and search
that reaches message bodies. Everything stays on the machine, and the plugin
needs no account, API key, or external service.

## For agents

The bundled skill tells an agent to keep one honest line current describing
where the work stands, and to say explicitly what it needs from you when it is
stuck. That line is what makes picking a thread back up take two seconds
instead of reading a transcript.
